Moonin Agent Chart

Repositorio público de Helm para instalar los agentes de Moonin en tus clústers de Kubernetes. Agrega este repositorio con helm repo add o instala el chart desde OCI en GHCR.

Instalación

helm repo add moonin-agent https://Moonin-Lab.github.io/Moonin-Agent-Chart
helm repo update
